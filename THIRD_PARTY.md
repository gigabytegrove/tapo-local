# Third-party software

## python-kasa

TP-Link Local uses [python-kasa](https://github.com/python-kasa/python-kasa) as a runtime dependency.

- Package: `python-kasa`
- Version pinned by this project: `0.10.2`
- License: GPL-3.0-or-later
- Source: https://github.com/python-kasa/python-kasa

python-kasa is installed as a separate Home Assistant Python dependency through the integration manifest and is not vendored into this repository.

The TP-Link Local project does not copy python-kasa source files into `custom_components/tapo_local`.
